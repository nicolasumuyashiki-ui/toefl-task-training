💡 LCR 攻略のコツ💡 LCR strategy tips
1
最初の2語に全集中 — Is there / Would you / Did you → 質問タイプを瞬時に判断Focus on the first 2 words — Is there / Would you / Did you → instantly identify the question type
2
質問タイプを判断してから選ぶ — 場所の質問には場所情報、提案には賛否＋具体的反応Identify the question type, then choose — location questions need location info; suggestions need agreement + a concrete reaction
3
「会話を前に進める応答」が正解 — 質問の単語が含まれていても、会話が止まる選択肢は不正解The choice that moves the conversation forward is correct — just including a keyword from the prompt is not enough; an option that ends the talk is wrong
4
一般論は不正解のサイン — 「〜は大事だ」「〜には歴史がある」のような一般的コメントは会話を発展させないWatch for hesitation/uncertainty expressions — "I'm not sure", "I'm worried" → reassurance + concrete advice is the natural reply
