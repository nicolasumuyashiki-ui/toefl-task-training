💡 Build a Sentence 攻略 3ステップ

1

主語と動詞を見つける

「誰が（主語）」「どうする（動詞）」を最初に探す。この2つが文の骨格。

2

骨格を作る

S+V を組み合わせて基本形を作る。文型（SV, SVC, SVO）を意識。

3

残りを配置

修飾語、前置詞句、接続詞を適切な位置に。最後に音読チェック（5秒）。

📐 今回の語順パターン

🔹 仮定法過去完了（Third Conditional）

Q1, Q5, Q9, Q14: If + S + had + Vpp, S + would have + Vpp。「もし〜していたら、〜だっただろう」過去の事実に反する仮定。

🔹 so/such ... that 構文

Q2, Q12: so + 形容詞 + that / Q7, Q16: such + 名詞句 + that。「あまりに〜なので…」結果を表す。

🔹 not only ... but also

Q3, Q10, Q15: Not only + V1 ... but also + V2。2つの効果・特徴を強調する相関接続詞。

🔹 despite / in spite of + 名詞句

Q4, Q8, Q13: Despite/In spite of + 名詞句, S + V。「〜にもかかわらず」逆接を表す前置詞。
