💡 Build a Sentence 攻略 3ステップ

1

主語と動詞を見つける

「誰が（主語）」「どうする（動詞）」を最初に探す。この2つが文の骨格。

2

骨格を作る

S+V を組み合わせて基本形を作る。文型（SV, SVC, SVO）を意識。

3

残りを配置

修飾語、前置詞句、接続詞を適切な位置に。最後に音読チェック（5秒）。

📐 今回の語順パターン

🔹 未来完了 (will have + Vpp)

Q1「will have snowed」Q6「will have completed」Q10「will have visited」— By + 時点 と組み合わせて「〜までに…しているだろう」。

🔹 unless / as long as

Q2「unless it rains」Q9「as long as the trail is not」Q13「unless I have to」Q16「as long as there is no」— 条件の接続詞。unless =「〜しない限り」、as long as =「〜する限り」。

🔹 both...and / neither...nor

Q3「both the warm weather and」Q7「neither the weather nor」Q11「both swimming ... and」— 相関接続詞。並列する要素の品詞を揃える。

🔹 使役動詞 (have/get + O + Vpp)

Q4「had it repaired」Q8「got the engine checked」Q12「had my brother help me」Q15「got it washed」— have/get + 目的語 + 過去分詞で「〜してもらう」。

🔹 前置詞付き関係代名詞

Q5「in which we played」Q14「at which we stayed」— 前置詞 + which で場所や手段を説明する形容詞節を作る。
