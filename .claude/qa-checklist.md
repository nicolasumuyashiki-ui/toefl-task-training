# QA Checklist — 問題品質チェックリスト (v1)

毎回の問題作成後に必ず実施すること。

## チェック項目
- [ ] 正解が2つ以上存在しないか
- [ ] 正解がないものはないか
- [ ] 正解が他の選択肢より目立っていないか（メタ的に答えがわかる）
- [ ] 本文から答えが見つけられるか
- [ ] 問題として破綻していないか
- [ ] （穴埋め）s + a = w が一致しているか
- [ ] 選択肢に被りがないか
- [ ] 問題に被りがないか（過去Practiceとも）
- [ ] 難易度設定にズレがないか
- [ ] 選択肢が安直すぎないか（言い換えになっているか）
- [ ] 正解分布がA/B/C/D均等か（1タスク内で67%以上の偏りはNG）
- [ ] CTW: 20語ターゲット、交互パターン、M1/M2H仕様
