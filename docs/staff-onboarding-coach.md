# 学習相談コーチの方へ — TCK Reps アプリ仕様の概要

TCK Workshop の TOEFL® 学習アプリ「TCK Reps」をご利用中の生徒さんへの月次学習相談を担当いただきありがとうございます。下記、アプリの仕組みとコーチの関わり方をまとめます。

---

## 1. アプリの全体像

- **URL**: https://apps.tckworkshop.co.jp/toefl-task-training/
- **対象**: 月額サブスクで利用する TOEFL iBT（2026 年新形式）対策アプリ
- **タスク数**: 全 4 技能 × 約 12 種類のタスクトレーニング、各 10 Practice ずつ
- **運用イメージ**: 生徒さんは毎日少しずつ Practice を消化、月 1 回コーチと振り返り

## 2. 学習相談の役割

「個別指導オプション（講師による添削・1on1）」とは**役割が異なります**。

| | コーチング相談 | 個別指導オプション |
|---|---|---|
| 担当 | コーチ | 講師 |
| 頻度 | 月 1 回（含まれる） | 都度購入（有料 ¥10,000） |
| 時間 | 45 分 | 60 分 |
| 主目的 | **学習計画・モチベ・全体方針／英語学習の幅広い相談** | **添削・解説・実践練習** |
| 扱う内容 | 進捗確認、目標設定、TOEFL 以外の英語学習相談、帰国子女入試・TOEFL 利用入試・留学準備など | 個別問題の解説、Writing 添削、Speaking 模範解答 |

> 学習相談は **TOEFL 対策に限らず**、今後の英語学習全般・帰国子女入試・国内大学の TOEFL 利用入試・海外大学進学準備など、英語に関わるあらゆるテーマを扱います。生徒さんが「何を相談すべきか分からない」と言ってきても、対話の中で論点を引き出してください。

→ コーチは「**伴走者**」、講師は「**技能指導者**」というイメージです。

## 3. セッション中に確認するとよい指標

### Predicted Score（予想スコア）
- 生徒さんの Activity 履歴（自動採点 R&L の正答率）から ETS 公式換算で算出
- **120 点満点（旧スケール）+ 1.0-6.0 バンド（2026 新スケール）両表示**
- **1 回目の素点ベース**。やり直しでは更新されない
- Speaking は採点不可、Writing は Build a Sentence 推測値のため表示されないか低信頼

### Mastery Rate（習得率）
- **最新の挑戦結果**ベース。同じ問題を何度もやり直して 100% 取れた割合
- Predicted と別指標。Predicted は本番予測、Mastery は復習成果

### Activity History（学習履歴）
- 受験した Practice ごとに「Perfect / Great / Good / Keep Going」のバッジ
- 中断した問題は「In Progress」表示
- 「復習する」リンクからジャンプ可

## 4. セッション中によく話す内容

- **目標スコアと現状ギャップ**: Predicted Score と本番目標を比較
- **学習ペース**: 週何 Practice、月どこまで進めるか
- **苦手技能の特定**: スコア乖離が大きい技能を特定し対策提案
- **中断癖の改善**: In Progress が多い場合は「最後までやる」習慣化
- **個別指導の必要性**: Writing / Speaking の改善には講師セッションを案内

## 5. コーチがアプリ上で確認できる情報

**現状、コーチアカウントは用意していません。** 生徒さんに以下の画面をスクショ共有してもらうのが基本フローです：

- `my-score.html` — Predicted Score 全体ビュー
- `my-score.html` — 「学習履歴」セクション
- 各タスクの解答結果ページ（必要に応じて）

→ 将来的に「コーチ向けダッシュボード」実装の可能性ありますが、現状は生徒経由でお願いします。

## 6. アプリ仕様で押さえておきたい用語

| 用語 | 意味 |
|---|---|
| **Module 1 / Easier / Harder** | TOEFL 2026 のアダプティブ方式に準拠。Module 1 は標準難度、Module 2 は前半成績で Easier または Harder に分岐 |
| **Band Score 1.0-6.0** | ETS が 2026 年 1 月から導入した新スケール。0.5 刻み |
| **Mastery Rate** | 復習による習得度。最新の挑戦結果ベース |
| **Harder バッジ** | Reading / Listening の難問パートに表示される「⚡ HARDER」表示 |

## 7. 学習相談 → 個別指導への誘導タイミング

セッション中、こんな兆候があれば **講師の個別指導オプション**（¥10,000 / 60分）をご案内ください：

- Writing の Email / Discussion を「書いたけど自信ない」と言っている
- Speaking の録音を「自分で聞いても良し悪しが分からない」と言っている
- 同じ Reading 問題タイプ（推論など）を何度ミスしている
- スコア停滞期に入っている

→ 案内方法: **メニュー → 個別指導オプション** に申し込みリンクあり
