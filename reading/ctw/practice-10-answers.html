💡 Complete the Words 攻略 4つのポイントFour keys to Complete the Words

01

品詞を特定してから埋めるIdentify the part of speech first

冠詞＋空欄 → 名詞
主語＋空欄 → 動詞
be動詞＋空欄 → 形容詞/過去分詞
空欄＋名詞 → 形容詞Article + blank → noun
Subject + blank → verb
Be + blank → adj/participle
Blank + noun → adj

02

頻出パターンを暗記するMemorize recurring patterns

however, therefore, although
particularly, especially
significant, demonstrate, evidence

→ 見たら即座に埋められるように！→ Recognize them instantly so you can fill the blank on sight.
03

推測でも必ず埋めるAlways fill the blank

正解 → 得点 / 不正解 → 0点 / 空欄 → 0点Correct → points / Wrong → 0 / Blank → 0

→ 推測しないと損！必ず何か入れよう→ A blank scores the same as a wrong guess — always write something.
04

INTROとCONCLUSIONを先に読むRead intro and conclusion first

最初と最後の文を先に読めば、トピックと流れが掴める。空欄の推測精度が上がる！The opening and closing sentences tell you the topic and flow — better context means better guesses.

→ 本文に入る前にまず全体像を把握→ Get the big picture before diving into the passage.

⚠️

スコアリングのルール — 推測しないと損！Scoring — always guess

Complete the Words では、正解 → 得点、不正解 → 0点、空欄 → 0点 です。不正解でも空欄でも結果は同じ0点。わからなくても必ず何か入力しましょう。In Complete the Words: correct → points, wrong → 0, blank → 0. A blank scores the same as a wrong answer — always write something, even a guess.
