Strategy

CTW 攻略 4 つのポイントFour keys to CTW

01

品詞を特定してから埋めるIdentify the part of speech first

冠詞＋空欄 → 名詞／主語＋空欄 → 動詞／be 動詞＋空欄 → 形容詞・過去分詞／空欄＋名詞 → 形容詞Article + blank → noun · Subject + blank → verb · Be + blank → adj/participle · Blank + noun → adj

02

頻出パターンを暗記するMemorize recurring patterns

however, therefore, although, particularly, significant, demonstrate, evidence … 見たら即座に埋められるように。however, therefore, although, particularly, significant, demonstrate, evidence — recognize them instantly.

03

推測でも必ず埋めるAlways fill the blankAlways fill the blank

正解 → 得点／不正解 → 0 点／空欄 → 0 点。推測しないと損。Correct → points · Wrong → 0 · Blank → 0. Guessing costs nothing.

04

Intro と Conclusion を先に読むRead intro and conclusion first

最初と最後の文でトピックと流れを掴む。推測精度が上がる。The opening and closing sentences tell you the topic and flow — better context, better guesses.

Note

スコアリングのルール — 推測しないと損Scoring — always guess

Complete the Words では、正解 → 得点、不正解 → 0 点、空欄 → 0 点。不正解でも空欄でも結果は同じ 0 点。わからなくても必ず何か入力しましょう。In CTW: correct → points, wrong → 0, blank → 0. A blank scores the same as a wrong answer, so always write something — even a guess.
